# IIITN Fantasy Arena: System Presentation

I have created a premium, immersive presentation module for the IIITN Fantasy Arena. This module is designed to "wow" users with high-end cyberpunk aesthetics and a clear overview of the platform's capabilities.

## Key Features of the Presentation
- **Immersive Visuals**: 3D backgrounds, glassmorphism, and dynamic particle effects.
- **Multi-Sport Coverage**: Showcases support for Cricket, Football, F1, and Hackathons.
- **Tech Stack Overview**: Highlighting the use of Vite, React, Node.js, and Prisma.
- **AI Integration**: Highlighting "Champak AI" as the platform's intelligent companion.
- **Cinematic Experience**: Full-screen slider with cinematic animations and ambient glows.

## How to Access
1. Open the application.
2. Look for the **"Showcase"** link in the sidebar.
3. Use the **Left/Right Arrow keys** or the on-screen controls to navigate the slides.
